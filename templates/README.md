# Templates

**AtoZ CyberLabs | Write it up the same way every time**

Copy a template, fill in the [square brackets], and send it to AJ for review. Nothing is published without AJ's approval.

| Template | Use it for | Goes in |
|---|---|---|
| [Policy](policy-template.md) | A new rule everyone must follow (POL) | [policies/](../policies/) |
| [Service protocol](service-protocol-template.md) | Steps for a new data service (DS) | [data-services/](../data-services/) |
| [Diagnostic guide](guide-template.md) | Steps for a new device problem (DP) | the device folder, e.g. [iphone/](../iphone/) |
| [Repair case](case-template.md) | A real, finished, verified repair | [cases/](../cases/) |

**Which one do I need?**
- A rule ("we always / we never") → Policy
- Steps for a customer service → Service protocol
- Steps to find what's wrong with a device → Diagnostic guide
- A write-up of a repair you already did → Repair case
