## Bench rules

1. Follow the guide steps in order. Don't skip the intake checks.
2. Ask about the customer's data before any restore, reset or replacement. See [Data Services](data-services/).
3. Only use the tools listed in this toolbox on store computers.
4. Never take screenshots that show a customer's name, messages, photos, serial number or IMEI.
5. Customer details stay in the repair ticket, never in this toolbox or in team chat.
6. Found a mistake or a better fix? See [CONTRIBUTING.md](CONTRIBUTING.md).
