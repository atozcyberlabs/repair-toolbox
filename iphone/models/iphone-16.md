## Repair notes

- Battery removal uses a different process than older models. Follow the manual exactly. Apple's post-repair software tool (Repair Assistant) finishes the repair for supported parts. Run it when the manual recommends it, then do the [Post-Repair Checklist](../quality-checks/post-repair-checklist.md).
