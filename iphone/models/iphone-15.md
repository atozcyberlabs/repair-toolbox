## Repair notes

- First model in this list with USB-C instead of Lightning. Displays and cameras carry factory calibration values. Apple's post-repair software tool (Repair Assistant) finishes the repair for supported parts. Run it when the manual recommends it, then do the [Post-Repair Checklist](../quality-checks/post-repair-checklist.md).
