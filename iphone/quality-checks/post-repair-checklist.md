# iPhone: Post-Repair Verification

Run this after every repair, before the phone goes back to the customer. Mark each function Pass, Fail, or Not tested, and note it in the repair ticket.

| Function | How to test | Pass | Fail | Not tested |
|---|---|---|---|---|
| Power on / boot | Full restart, reaches lock screen | | | |
| Display | No lines, dead spots, or discoloration; brightness changes | | | |
| Touch | Drag an app icon across every part of the screen | | | |
| Face ID / Touch ID | Customer tests with their own face or finger | | | |
| Rear camera(s) | Photo and video on each lens, flash | | | |
| Front camera | Photo and video | | | |
| Speakers | Ringtone and media playback | | | |
| Microphones | Voice memo, speakerphone call, video recording | | | |
| Wired charging | Charges and shows the charging icon | | | |
| Wireless / MagSafe charging | Charges on a pad, if supported | | | |
| Buttons and switch | Power, volume up/down, mute/action button | | | |
| Cellular / Wi-Fi / Bluetooth | Signal bars, joins Wi-Fi, pairs a device | | | |
| Sensors | Proximity (screen off during call), auto-brightness | | | |
| Battery | Battery Health shows normally, no service message | | | |
| No new panic logs | Check Analytics Data after a 30-minute run | | | |

**If anything fails:** don't return the phone. Note what failed in the ticket and go back to the matching diagnostic guide, or contact AJ.

**Not tested** is fine when a function can't be checked (for example, the customer isn't there for Face ID), but write down why.
